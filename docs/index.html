What it does

Your DAM, inside your documents

🔍

Search & Insert

Search your Aprimo DAM and insert images directly at your cursor in Google Docs or onto your Slides canvas.

✏️

Open & Edit

Pull a DOCX, XLSX, or PPTX from Aprimo into Google Drive, edit it, and save it back as a new version — all without leaving Google.

⬆️

Upload Documents

Export and upload the currently open Google file to Aprimo as a new asset or a new version of an existing record.

💾

Save to Drive

One-click copy any DAM asset into your Google Drive for offline access or sharing with colleagues.

🕐

Recent Assets

The last 10 assets you touched are a single click away in the Recent tab, with full action buttons.

🔒

Secure by Design

OAuth 2.0 PKCE flow. Your Aprimo credentials are stored in your own Google user properties — never on a third-party server.

Transparency

Why each permission is needed

This add-on requests the minimum scopes required to function. No data is collected, logged, or transmitted to any server other than your own Aprimo tenant and Google's own services.

Permission Why it's needed
documents.currentonly Insert images and read the active document's ID and name for upload
spreadsheets.currentonly Read the active spreadsheet's name and ID for upload
presentations.currentonly Insert images onto slides and read the active presentation's ID for upload
drive.file Create temporary Drive files when pulling Office documents from Aprimo for editing; delete those files after re-upload
script.external_request Make HTTPS requests to your Aprimo tenant's API (search, download, upload)
userinfo.email Identify the current user so per-user settings (your Aprimo token) are stored separately from other users'
script.container.ui Show the sidebar panel inside Google Docs / Sheets / Slides
script.scriptapp Generate a short-lived OAuth token for Drive API calls within the add-on
